# Bergen Memory Bank v2

Evolve the faculty-facing Gemini Gem into a verified Google Keep read/write memory workflow and add a complete Canvas course-packaging handoff. Faculty can initialize and resume courses, automatically checkpoint low-risk work, approve durable memory, develop syllabus-aligned course content entirely in Gemini, and export one reviewed Bergen Course Transfer Block for a browser-only packager that creates an unpublished Common Cartridge (`.imscc`). The existing assessment-only QTI handoff remains available.
