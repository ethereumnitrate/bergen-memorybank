# Bergen Memory Bank Five-Minute Installation

This five-minute installation sets up the four faculty-controlled memory documents and the classic custom Gem. Use only teaching context and synthetic or de-identified class-level observations. Keep student records in Canvas.

## Optional preflight

Sign in to Gemini and Google Drive with your named `bergen.edu` account. Check whether your account offers classic custom Gems and permits Drive documents to be used as Gem knowledge. If either choice is unavailable, pause here and use the access guidance in Bergen Memory Bank Troubleshooting. This check is optional and is not an installation step.

## Eight required steps

1. Create a **Bergen Memory Bank** Google Drive folder.
2. Copy the four supplied templates into that folder: **Faculty Profile**, **Course Memory**, **Active Workbench**, and **Decisions, Reflections, and Reusable Practices**.
3. Create a classic custom Gem while signed in with your bergen.edu account.
4. Name the Gem **Bergen Memory Bank**.
5. Paste the supplied Bergen Memory Bank instructions into the Gem instructions area.
6. Attach the four Drive documents as Gem knowledge.
7. Save the Gem.
8. Open the saved Gem and enter `bergen:help`.

The Help response should begin `Bergen Memory Bank · Help`, show the safe workflow menu, and end with `Current stage: Remember` followed by a `Recommended next command:` line. The Gem does not edit the attached documents. After an approved record proposal, you paste the copy-ready text into the named Google Doc yourself.
