# Bergen Memory Bank Five-Minute Installation

This five-minute installation sets up the four faculty-controlled archive documents and the classic custom Gem. Google Keep is the active memory used from inside Gemini; the documents remain available as a curated archive. Use only teaching context and synthetic or de-identified class-level observations. Keep student records in Canvas.

## Optional preflight

Sign in to Gemini and Google Drive with your named `bergen.edu` account. Check whether your account offers classic custom Gems, permits Drive documents to be used as Gem knowledge, and offers the connected Google Keep action. If any choice is unavailable, pause here and use the access guidance in Bergen Memory Bank Troubleshooting. This check is optional and is not an installation step.

## Eight required steps

1. Create a **Bergen Memory Bank** Google Drive folder.
2. Copy the four supplied templates into that folder: **Faculty Profile**, **Course Memory**, **Active Workbench**, and **Decisions, Reflections, and Reusable Practices**.
3. Create a classic custom Gem while signed in with your bergen.edu account.
4. Name the Gem **Bergen Memory Bank**.
5. Paste the supplied Bergen Memory Bank instructions into the Gem instructions area.
6. Attach the four Drive documents as Gem knowledge.
7. Save the Gem.
8. Open the saved Gem and enter `bergen:help`.

The Help response should begin `Bergen Memory Bank · Help`, show all seventeen workflows, and end with `Current stage: Remember` followed by a `Recommended next command:` line. The Gem does not edit the attached documents. After you approve a durable record, Gemini may report it saved only after Google Keep creates the note, Gemini retrieves the exact new Keep note, and compares the full note with the approved content. If creation, retrieval, or comparison fails, the proposed content and failure remain visible in Gemini; the attached Google Docs remain an optional curated archive rather than a required recording step.

Google documents Gemini Apps creating and finding Keep notes in [Capture ideas and notes with Gemini Apps](https://support.google.com/gemini/answer/15230597?hl=en), conditional work-or-school availability in [Use connected apps with a work or school account](https://support.google.com/gemini/answer/14959807?hl=en), and administrator controls in [Control Gemini access to Workspace services](https://support.google.com/a/answer/15293691?hl=en). These sources do not prove that a Bergen classic custom Gem can complete a write; creation, exact-note retrieval, and full comparison must still be observed before Gemini reports success.
