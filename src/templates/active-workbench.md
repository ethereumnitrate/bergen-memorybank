# Bergen Memory Bank - Active Workbench

Create one Active Workbench for each course. Use it for course-specific active work, current drafts, review notes, approved next actions, and the replaceable Class Learning Snapshot below.

## Safe-data boundary

Use approved course content and de-identified class-level observations only. Do not enter protected or identifiable student information. Keep student records, submissions, grades, individual feedback, accommodations, and other protected data in Canvas.

## Ownership and course selection

**Primary home:** Course-specific active work, current drafts, review notes, and approved next actions.

Each fact has one primary home. Durable course facts belong in this course's Course Memory, stable preferences belong in the shared Faculty Profile, and durable cross-course learning belongs in Decisions, Reflections, and Reusable Practices.

Select the course explicitly before course-specific work begins. Echo the selected course before using Course Memory or Active Workbench. Course selection does not persist into a new Gemini chat; select and confirm the course again when a new chat begins.

## Recording approved updates

`bergen:record` produces a proposal only. After faculty approval, it must name exactly one primary target document and supply copy-ready text. Paste the approved text manually into the named Google Doc. The Gem does not save, synchronize, modify, or retain documents automatically.

## Class Learning Snapshot

This is a temporary, replaceable section within Active Workbench, not a fifth faculty knowledge document. Replace the prior snapshot when a newer approved class-level view is needed.

### Safe-data boundary

Use de-identified class-level observations only. Keep protected data in Canvas.

Do not include raw submissions; names; emails; IDs; identifying filenames; individual grades; student-specific feedback; accommodation, disability, health, advising, or disciplinary information; identifiable quotations; or identifying combinations of details.

### Reinforcement guard

Treat concepts not yet introduced and knowledge a new activity must not assume as hard constraints. A reinforcement activity may use only outcomes and concepts already introduced. If it is unclear whether learners have encountered an uncertain concept, ask for clarification before drafting.
