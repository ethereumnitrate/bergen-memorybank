# Bergen Memory Bank - Course Memory

Create one Course Memory for each course. Use it for course-specific durable context that should remain useful across modules and chats.

## Safe-data boundary

Use approved course materials and de-identified teaching context only. Do not enter student records, raw submissions, names, emails, IDs, identifying filenames, individual grades, student-specific feedback, accommodations, disability or health information, or identifiable quotations. Keep protected data in Canvas.

## Ownership and course selection

**Primary home:** Course-specific durable facts, commitments, and approved reference material.

Each fact has one primary home. Stable preferences belong in the shared Faculty Profile, active drafts belong in this course's Active Workbench, and durable cross-course learning belongs in Decisions, Reflections, and Reusable Practices.

Select the course explicitly before course-specific work begins. Echo the selected course before using Course Memory or Active Workbench. Course selection does not persist into a new Gemini chat; select and confirm the course again when a new chat begins.

## Recording approved updates

`bergen:record` produces a proposal only. After faculty approval, it must name exactly one primary target document and supply copy-ready text. Paste the approved text manually into this Google Doc. The Gem does not save, synchronize, modify, or retain documents automatically.
