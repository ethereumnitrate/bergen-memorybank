# Bergen Memory Bank - Faculty Profile

Use this form for stable preferences that apply across courses. Keep one shared Faculty Profile for all courses.

## Safe-data boundary

Use teaching preferences and professional context only. Do not enter student records, student-specific information, raw submissions, names, emails, IDs, grades, accommodations, health details, or identifiable quotations. Keep protected data in Canvas.

## Ownership and use

**Primary home:** Stable faculty preferences that apply across courses.

Each fact has one primary home. Put course-specific facts in that course's Course Memory, current work in that course's Active Workbench, and durable cross-course learning in Decisions, Reflections, and Reusable Practices.

## Recording approved updates

`bergen:record` produces a proposal only. After faculty approval, it must name exactly one primary target document and supply copy-ready text. Paste the approved text manually into this Google Doc. The Gem does not save, synchronize, modify, or retain documents automatically.
