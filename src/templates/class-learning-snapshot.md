## Class Learning Snapshot

This is a temporary, replaceable section within Active Workbench, not a fifth faculty knowledge document. Replace the prior snapshot when a newer approved class-level view is needed.

### Safe-data boundary

Use de-identified class-level observations only. Keep protected data in Canvas.

Do not include raw submissions; names; emails; IDs; identifying filenames; individual grades; student-specific feedback; accommodation, disability, health, advising, or disciplinary information; identifiable quotations; or identifying combinations of details.

### Reinforcement guard

Treat concepts not yet introduced and knowledge a new activity must not assume as hard constraints. A reinforcement activity may use only outcomes and concepts already introduced. If it is unclear whether learners have encountered an uncertain concept, ask for clarification before drafting.
