# Codex Project Guidance

This project uses the ALA Memory Bank v2 workflow.

- Start with `ala:go` to inspect durable state and choose the next safe action.
- Treat `memory-bank/projectConfig.md`, `productBrief.md`, `techContext.md`, and `systemPatterns.md` as durable project context.
- Keep task plans and execution state in `memory-bank/tasks/<slug>.md`.
- Preserve user changes and use proportionate, evidence-based verification for deliverables.
- Respect configured branch routing and protected branches.
- Never add usage telemetry, analytics, session hooks, transcript logging, or external collectors.
- Keep faculty-facing deliverables no-code and free of Git, terminal, API, and developer terminology.
- Never place protected or identifiable student information in repository artifacts, Gemini instructions, prompts, examples, or attached knowledge documents.
- Treat Canvas as the student-record system and require faculty approval before revisions, memory updates, or publication guidance.
